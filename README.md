# Soil microbiome NGS workflow

Bioinformatics workflow developed for processing **Illumina MiSeq paired-end
16S rRNA amplicon sequencing data** from soil microbiome research.

The repository preserves the computational workflow used for sequence processing
and analysis associated with my research conducted in 2017–2018.

## Scope

- Illumina MiSeq paired-end amplicon sequencing
- 16S rRNA sequence processing
- soil microbiome analysis
- microbial community analysis
- reproducible bioinformatics workflow
- Jupyter-based sequence processing

## Background

This repository is retained as a historical, reproducible record of an early
NGS bioinformatics workflow used in my soil microbial ecology research.

My current work extends these interests toward modern microbiome,
metagenomics, transcriptomics, reproducible scientific computing, and
AI-assisted scientific workflows.
